# MetaSafe. Поддержка форматов и просмотр метаданных

В окне MetaSafe откройте фото и нажмите стрелку у категории со статусом **«Найдено»**. В строке раскроются доступные названия и значения полей. Поддерживаемые категории включают EXIF, GPS, XMP, IPTC, комментарии и ICC. Категории, которые не удалось проверить, имеют отдельный статус.

MetaSafe открывает JPEG, PNG, APNG, WebP, GIF, TIFF, BMP, ICO, TGA, QOI, PNM, HDR и поддерживаемые варианты DDS напрямую. HEIC/HEIF, AVIF, PSD/PSB, JPEG 2000, JPEG XL и RAW используют локальные инструменты. Их установка описана в [README](../README.ru.md#форматы-в-текущих-исходниках).

Пакетная обработка создаёт JPEG-копии для JPEG и PNG-копии для остальных входов. PNG сохраняет прозрачность. Для анимаций, многостраничных файлов и документов со слоями копия содержит одно изображение. Оригиналы сохраняются.

На macOS прошли 25 тестов Rust, включая проверку прозрачности PNG, первый кадр GIF, комментарии JPEG и смешанную пакетную обработку. HEIC, AVIF, PSD и синтетический DNG проверены отдельно через открытие, очистку в PNG и повторную проверку копии. В собранном окне раскрыта строка PNG с полем автора. Windows, JPEG 2000, JPEG XL и отдельные модели RAW-камер требуют проверки на соответствующих кодеках.
