# MetaSafe

[English](README.md) · [Русский](README.ru.md) · [Скачать v0.8.1](https://github.com/V3rCg1/MetaSafe/releases/tag/v0.8.1) · [Изменения](docs/releases/v0.8.1.md) · [Лицензия MIT](LICENSE)

MetaSafe просматривает и удаляет поддерживаемые метаданные фотографий, видео и документов на вашем устройстве. Программа создаёт отдельную проверенную копию и сохраняет оригинал. Есть приложение для macOS, Windows и Linux и командная строка.

JPEG, PNG, WebP, PDF, DOCX и XLSX работают без дополнительных программ. Для видео нужен FFmpeg. Остальные форматы изображений используют локальные инструменты, перечисленные ниже.

Готовые сборки приложения доступны для этих архитектур. Пакетов для macOS Intel и Linux ARM64 в этом релизе нет.

### macOS

1. Распакуйте архив и перенесите `MetaSafe.app` в папку «Программы».
2. Откройте MetaSafe из этой папки.
3. Приложение не нотарифицировано Apple. Если macOS блокирует запуск, сверьте контрольную сумму. Для загрузки, которой вы доверяете, откройте **Системные настройки > Конфиденциальность и безопасность > Всё равно открыть**. Кнопка появляется после заблокированной попытки запуска.

Для видео установите [Homebrew](https://brew.sh/), если его ещё нет, и выполните:

```sh
brew install ffmpeg
```

После установки инструментов перезапустите MetaSafe. Для обычной очистки фото и документов FFmpeg не нужен.

### Windows

1. Скачайте и запустите `MetaSafe_0.8.1_x64-setup.exe`.
2. Завершите установку и откройте MetaSafe через меню «Пуск».
3. Установщик не подписан коммерческим сертификатом подписи кода. Если SmartScreen блокирует запуск, проверьте контрольную сумму. Для загрузки, которой вы доверяете, выберите **Подробнее > Выполнить в любом случае**.

Приложение использует Microsoft Edge WebView2. Если установщик предлагает установить эту среду, дождитесь завершения. Для её загрузки может понадобиться интернет.

Для видео установите сборку [FFmpeg для Windows](https://ffmpeg.org/download.html), добавьте папку с `ffmpeg.exe` и `ffprobe.exe` в `PATH` и перезапустите MetaSafe. В новом терминале должны работать команды:

```powershell
ffmpeg -version
ffprobe -version
```

### Linux

В папке со скачанным пакетом выполните:

```sh
sudo apt install ./MetaSafe_0.8.1_amd64.deb
```

APT установит FFmpeg и зависимости рабочего стола. Запускайте MetaSafe через меню приложений. Пакет собирается на Ubuntu 24.04; для других систем нужны совместимые библиотеки или [сборка из исходников](#сборка-из-исходников). Рекомендованные пакеты GStreamer расширяют поддержку воспроизведения.

## Что изменилось в v0.8.1

При загрузке PDF действует общий бюджет декодирования 64 МиБ для потоков объектов, таблиц ссылок и промежуточных фильтров сжатия. Предел 8 МиБ на отдельный поток сохраняется. При превышении любого предела программа отклоняет файл до публикации очищенной копии.

Семь регрессионных тестов проверяют суммарную распаковку, вложенные фильтры, косвенные длины потоков, пустые массивы фильтров и предыдущие ревизии PDF. Обычная очистка сохраняет проверенное содержимое страниц, ссылки и поля форм. Реализация, проверки и ограничения описаны в [подробных заметках к релизу](docs/releases/v0.8.1.md).

## Возможности

- Просмотр метаданных фото и видео, включая EXIF, координаты GPS и комментарии, если они есть.
- Просмотр и удаление поддерживаемых свойств PDF, DOCX и XLSX.
- Очистка отдельных файлов или целой партии с сохранением оригиналов.
- Очистка статических JPEG, PNG и WebP без перекодирования.
- Очистка MP4, MOV, MKV и WebM без перекодирования с сохранением дорожек субтитров и HDR по умолчанию.
- Воспроизведение совместимых видео во встроенном плеере. Поддержка зависит от системных кодеков.

## Работа в окне программы

1. В окне программы нажмите «Открыть файлы» и выберите фото, видео или документы. Файлы также можно перетащить в окно.
2. Выберите файл в списке, чтобы увидеть метаданные и превью для поддерживаемых медиафайлов. Нажмите на строку «Найдено», чтобы посмотреть значения. Сведения EXIF могут содержать точные координаты.
3. Для одного файла нажмите «Создать очищенную копию…» и укажите имя. Для нескольких нажмите «Создать очищенные копии…» и выберите папку.
4. Дождитесь завершения и раскройте отчёт по нужному файлу.

При пакетной обработке `photo.jpeg` сохраняется как `photo_clean.jpg`. Если это имя уже занято, программа сообщает об ошибке для этого файла и продолжает обработку остальных. Файлы с одинаковым базовым именем обрабатывайте в разные папки. В переключателе «Тема» справа вверху доступны системная, светлая и тёмная темы; выбор сохраняется. Язык можно переключить в правом верхнем углу.

## Работа в командной строке

Пример для macOS. Замените имена путями к своим JPEG. Папка `cleaned` должна существовать до запуска пакетной очистки.

```sh
./metasafe inspect "photo 1.jpg"
./metasafe clean "photo 1.jpg" --output "photo 1_clean.jpg"
./metasafe verify "photo 1_clean.jpg"
mkdir -p cleaned
./metasafe batch "photo 1.jpg" "photo 2.jpeg" --output-dir cleaned
```

Пример для PowerShell:

```powershell
.\metasafe.exe inspect "photo 1.jpg"
.\metasafe.exe clean "photo 1.jpg" --output "photo 1_clean.jpg"
.\metasafe.exe verify "photo 1_clean.jpg"
New-Item -ItemType Directory -Force cleaned
.\metasafe.exe batch "photo 1.jpg" "photo 2.jpeg" --output-dir cleaned
```

- `inspect` показывает результаты анализа контейнера и поля EXIF.
- `clean` применяет EXIF Orientation, сохраняет временную копию рядом с файлом назначения, проверяет её и публикует без перезаписи. При повреждённом EXIF или неоднозначной ориентации возвращает ошибку.
- `verify` возвращает код 0, если проверки пройдены, 1, если найдены метаданные или проверка неполная, и 2 при ошибке ввода, чтения или декодирования.
- `batch` возвращает код 0, если сохранены все копии, 1, если хотя бы один файл завершился ошибкой, и 2 при общей ошибке, например если папка назначения отсутствует.

## Форматы изображений

| Исходный формат | Просмотр и проверка метаданных | Копия по умолчанию в приложении | Без перекодирования |
| --- | --- | --- | --- |
| JPEG | EXIF, GPS, XMP, IPTC, комментарии, ICC и неизвестные или лишние данные | JPEG | Статический JPEG без обязательных преобразований |
| PNG | EXIF, GPS, текст, XMP, ICC и неизвестные или лишние данные | PNG | Статический PNG без обязательных преобразований |
| WebP | EXIF, GPS, XMP, ICC и неизвестные или лишние данные | PNG | Статический WebP без обязательных преобразований |

MetaSafe открывает JPEG, PNG, APNG, WebP, GIF, TIFF, BMP, ICO, TGA, QOI, PNM, HDR и поддерживаемые варианты DDS напрямую. Для HEIC/HEIF, AVIF, PSD/PSB, JPEG 2000, JPEG XL и форматов RAW нужны локальные инструменты.

- ExifTool читает метаданные дополнительных форматов.
- ImageMagick с нужными кодеками открывает HEIC/HEIF, AVIF, PSD/PSB, JPEG 2000 и JPEG XL.
- LibRaw с утилитой `dcraw_emu` открывает RAW, включая DNG, CR2/CR3, NEF, ARW, RAF и RW2, если поддерживается модель камеры.

На macOS установите инструменты командой `brew install imagemagick exiftool libraw`. Для JPEG 2000 и JPEG XL нужна сборка ImageMagick с соответствующими кодеками. На Windows добавьте исполняемые файлы в PATH. Абсолютные пути можно задать через `METASAFE_MAGICK`, `METASAFE_EXIFTOOL` и `METASAFE_DCRAW_EMU`.

Откройте файлы в окне программы. Нажмите стрелку рядом с категорией **«Найдено»**, чтобы увидеть поля. Отдельно отмечаются категории, которые не удалось проверить. При пакетной обработке JPEG сохраняется как JPEG, остальные форматы как PNG. PNG сохраняет прозрачность. Из анимированных и многостраничных файлов создаётся копия одного изображения без анимации и слоёв.

## Очистка без перекодирования

В окне программы включите **«Без перекодирования»** перед сохранением файла или пакета. Тот же режим доступен в CLI.

```sh
metasafe clean photo.webp --output photo_clean.webp --no-reencode
metasafe batch photo.jpg diagram.png image.webp --output-dir cleaned --no-reencode
```

Режим удаляет метаданные контейнера из статических JPEG, PNG и WebP и копирует сжатые данные изображения. Формат файла и прозрачность PNG и WebP сохраняются. Для анимации и файлов, которым нужен поворот или преобразование цвета, программа сообщает об ошибке и продолжает обрабатывать остальные файлы пакета. Удаление цветового профиля может изменить отображение цветов.

## Видео

Приложение и CLI открывают MP4, MOV, MKV и WebM. Установите `ffmpeg` и `ffprobe` и добавьте их в `PATH`. В окне программы можно просмотреть метаданные и воспроизвести совместимые дорожки, затем сохранить очищенные копии одного или нескольких файлов. Воспроизведение зависит от кодеков, доступных системному веб-движку.

```sh
metasafe inspect clip.mkv
metasafe clean clip.mkv --output clip_clean.mkv
mkdir -p cleaned
metasafe batch clip.mkv recording.webm --output-dir cleaned
metasafe verify cleaned/recording_clean.webm
```

При обычной очистке закодированные видео, звук и субтитры копируются в тот же формат контейнера. Программа удаляет поддерживаемые теги контейнера и главы, сохраняя текст субтитров и сигналы HDR. Перед публикацией просмотрите содержимое субтитров. Matroska-файлы с вложениями, например шрифтами, отклоняются, чтобы очистка не меняла отображение субтитров без предупреждения.

Опция `--strip-h264-sei` удаляет сообщения SEI из пакетов H.264 без перекодирования. Используйте её только для совместимого SDR-видео H.264. При обнаружении HDR или встроенных титров фильтрация отклоняется. Фильтр удаляет все обнаруженные сообщения SEI, включая другие данные, которые они могут содержать. Размер видео должен быть меньше 2 ГиБ, число дорожек не должно превышать 32. Для больших файлов требуется свободное место для временного снимка исходника и очищенной копии. Отчёт не подтверждает удаление персональных данных внутри кодированных потоков и текста субтитров. Универсальной очистки потока для других кодеков, Dolby Vision, HDR10+ и произвольных данных нет.

## Документы

MetaSafe показывает и удаляет свойства PDF и XMP документа. Для DOCX и XLSX программа обрабатывает основные и пользовательские свойства и отдельные расширенные поля, например Company и Manager. Обработка выполняется на устройстве. Программа создаёт отдельную копию в исходном формате и повторно проверяет поддерживаемые свойства перед сохранением.

```sh
metasafe inspect draft.docx
metasafe clean report.pdf --output report_clean.pdf
metasafe verify report_clean.pdf
metasafe batch draft.docx budget.xlsx report.pdf --output-dir cleaned
```

В PDF сохраняются страницы, ссылки и данные форм. Вложения, аннотации, метаданные отдельных объектов и идентификаторы PDF остаются вне области очистки. Содержимое документов Office, включая комментарии, правки, скрытые листы и ссылки, сохраняется. Программа отклоняет очистку подписанных и зашифрованных файлов и PDF/A. Поля Word, зависящие от свойств документа, тоже могут заблокировать очистку.

## Воспроизведение и сборка в Linux

В Linux встроенный плеер получает выбранное видео через локальный адрес на том же устройстве (`127.0.0.1`).

Проверки GitHub Actions собирают CLI и пакет Tauri `.deb` на Ubuntu 24.04. Для локальной сборки установите [зависимости Tauri для Linux](https://v2.tauri.app/start/prerequisites/#linux) и выполните команды из раздела ниже. Чтобы собрать пакет `.deb`, запустите `npm run tauri build -- --bundles deb` в папке `desktop/`. Для CLI выполните `cargo build --release --locked --no-default-features` в корне проекта.

## Сборка основного приложения

Установите Node.js 22.13 или новее, Rust 1.90 или новее и [системные зависимости Tauri](https://v2.tauri.app/start/prerequisites/). В Windows нужны средства сборки Microsoft C++ и WebView2. В macOS установите Xcode Command Line Tools командой `xcode-select --install`. Для Linux пакеты перечислены по ссылке. Сначала клонируйте репозиторий, затем выполните из его корня:

```sh
cd desktop
npm ci
npm run tauri dev
```

Для сборки приложения под текущую ОС выполните `npm run tauri build` из папки `desktop/`.

## Сборка из исходников

Клонируйте репозиторий вместе с папкой `vendor/lopdf`. Нужен Rust 1.88 или новее. Команда ниже собирает CLI и старый интерфейс eframe; основное приложение собирается по инструкции Tauri выше.

```sh
git clone https://github.com/V3rCg1/MetaSafe.git
cd MetaSafe
```

В корне проекта выполните:

```sh

```

Исполняемые файлы появятся в `target/release` (с расширением `.exe` в Windows). Можно также установить оба приложения через `cargo install --path . --locked`. Для сборки только CLI используйте `cargo build --release --locked --no-default-features --bin metasafe`.

## Границы проверки

Размер исходных и выходных фотографий и документов ограничен 64 МиБ.

Для каждой поддерживаемой проверки отчёт показывает один из статусов: **«Найдено»**, **«Не найдено»** или **«Не проверено»**. Для изображений команда `verify` также пробует декодировать файл. В JPEG допускается служебный заголовок JFIF без миниатюры. Проверки конкретных форматов перечислены в таблице изображений и в разделе о видео.

Обычная очистка JPEG сохраняет копию с качеством 90. Размер, качество и цветопередача могут измениться. Лица, адреса и другие детали остаются в пикселях. Речь, субтитры и текст в кадре тоже могут раскрывать личную информацию. Успешный отчёт не подтверждает анонимность.

Разбор EXIF ограничен 1 024 полями, 32 каталогами TIFF и оценкой памяти в 1 МиБ. При превышении предела программа отмечает EXIF и GPS как непроверенные и отклоняет очистку.

Загрузка PDF ограничена 8 МиБ на распакованный поток и общим бюджетом 64 МиБ на результаты успешного декодирования, включая промежуточные фильтры и повторную распаковку при чтении ревизий. Для XMP каталога отдельно действует предел 1 МиБ. Превышение предела останавливает обработку без создания копии. Эти бюджеты не ограничивают всю память процесса.

Выбирайте папку вывода, которую могут изменять только доверенные пользователи. Это касается и родительских папок. MetaSafe сравнивает опубликованный файл с проверенной копией и сообщает о расхождении. Процесс с правом записи может подменить файл во время проверки или после неё.

Предел для исходных и выходных фотографий составляет 64 МиБ. Для декодирования действуют пределы 16 384 пикселя на сторону и 40 мегапикселей. Лимит выделений декодера применяется по возможности и не ограничивает всю память процесса. При аварийном завершении временный файл может остаться в папке назначения.

## Разработка и лицензия

Общее ядро Rust находится в `src/core`, основное приложение на Tauri и React в `desktop`. Локальный патч бюджета PDF описан в [vendor/lopdf/PATCHES.md](vendor/lopdf/PATCHES.md). Сохраняйте эту папку при сборке из исходников.

```sh
cargo fmt --all -- --check
```
