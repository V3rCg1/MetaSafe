# MetaSafe v0.6.0

**Русский** · [English](README.md)

MetaSafe — приложение и CLI с открытым исходным кодом для просмотра метаданных фотографий и видео и создания проверенных копий. Обработка идёт на устройстве, оригиналы сохраняются. Код доступен по [лицензии MIT](LICENSE).

## Скачать

[Скачать MetaSafe v0.6.0](https://github.com/V3rCg1/MetaSafe/releases/latest). Графическое приложение теперь доступно для Linux в виде пакета Debian. На Debian ARM64 выполните `sudo apt install ./MetaSafe_0.6.0_arm64.deb` в папке загрузки. Архитектура указана в имени файла релиза.

### Проверка графического приложения

| Система | Что проверено в окне приложения |
| --- | --- |
| Debian 12 ARM64 | Метаданные JPEG и сохранение одной копии, пакет JPEG и WebM, воспроизведение MP4, MKV и WebM |
| macOS Apple Silicon | Метаданные JPEG и сохранение одной копии, пакет JPEG и MP4, воспроизведение MP4. Системный диалог блокировал открытие тестовых MKV и WebM |
| Windows 11 ARM64 и Windows Server 2025 x64 | Метаданные JPEG и сохранение одной копии, пакет JPEG и MP4, воспроизведение MP4, MKV и WebM |

Windows проверялась на тестовых сборках с системными диалогами. Windows 10 и Windows-установщик в эту проверку не входили. Воспроизведение зависит от системных кодеков. Для просмотра и очистки метаданных видео нужны FFmpeg и FFprobe, если они не установились вместе с пакетом.

В этой версии исправлены три замечания Codex Security. Проверка PNG обнаруживает лишние данные внутри IDAT, проверка GIF учитывает структуру расширений анимации, а плеер Linux проверяет запросы перед передачей обработчикам воспроизведения.

## Работа в окне программы

1. В окне Tauri нажмите «Открыть файлы» и выберите фото или видео. Файлы также можно перетащить в окно.
2. Выберите файл в списке, чтобы увидеть превью и метаданные. Нажмите на строку «Найдено», чтобы посмотреть значения. Сведения EXIF могут содержать точные координаты.
3. Для одного файла нажмите «Создать очищенную копию…» и укажите имя. Для нескольких нажмите «Создать очищенные копии…» и выберите папку.
4. Дождитесь завершения и раскройте отчёт по нужному файлу.

При пакетной обработке `photo.jpeg` сохраняется как `photo_clean.jpg`. Если это имя уже занято, программа сообщает об ошибке для этого файла и продолжает обработку остальных. Файлы с одинаковым базовым именем обрабатывайте в разные папки. Интерфейс следует теме системы. Язык можно переключить в правом верхнем углу.

## Работа в командной строке

Пример для macOS. Замените имена путями к своим JPEG. Папка `cleaned` должна существовать до запуска пакетной очистки.

```sh
./metasafe inspect "photo 1.jpg"
./metasafe clean "photo 1.jpg" --output "photo 1_clean.jpg"
./metasafe verify "photo 1_clean.jpg"
mkdir -p cleaned
./metasafe batch "photo 1.jpg" "photo 2.jpeg" --output-dir cleaned
```

Пример для PowerShell:

```powershell
.\metasafe.exe inspect "photo 1.jpg"
.\metasafe.exe clean "photo 1.jpg" --output "photo 1_clean.jpg"
.\metasafe.exe verify "photo 1_clean.jpg"
New-Item -ItemType Directory -Force cleaned
.\metasafe.exe batch "photo 1.jpg" "photo 2.jpeg" --output-dir cleaned
```

- `inspect` показывает результаты анализа контейнера и поля EXIF.
- `clean` применяет EXIF Orientation, сохраняет временную копию рядом с файлом назначения, проверяет её и публикует без перезаписи. При повреждённом EXIF или неоднозначной ориентации возвращает ошибку.
- `verify` возвращает код 0, если проверки пройдены, 1, если найдены метаданные или проверка неполная, и 2 при ошибке ввода, чтения или декодирования.
- `batch` возвращает код 0, если сохранены все копии, 1, если хотя бы один файл завершился ошибкой, и 2 при общей ошибке, например если папка назначения отсутствует.

## Форматы в текущих исходниках

MetaSafe открывает JPEG, PNG, APNG, WebP, GIF, TIFF, BMP, ICO, TGA, QOI, PNM, HDR и поддерживаемые варианты DDS напрямую. Для HEIC/HEIF, AVIF, PSD/PSB, JPEG 2000, JPEG XL и форматов RAW нужны локальные инструменты.

- ExifTool читает метаданные дополнительных форматов.
- ImageMagick с нужными кодеками открывает HEIC/HEIF, AVIF, PSD/PSB, JPEG 2000 и JPEG XL.
- LibRaw с утилитой `dcraw_emu` открывает RAW, включая DNG, CR2/CR3, NEF, ARW, RAF и RW2, если поддерживается модель камеры.

На macOS установите инструменты командой `brew install imagemagick exiftool libraw`. Для JPEG 2000 и JPEG XL нужна сборка ImageMagick с соответствующими кодеками. На Windows добавьте исполняемые файлы в PATH. Абсолютные пути можно задать через `METASAFE_MAGICK`, `METASAFE_EXIFTOOL` и `METASAFE_DCRAW_EMU`.

Откройте файлы в окне Tauri. Нажмите стрелку рядом с категорией **«Найдено»**, чтобы увидеть поля. Отдельно отмечаются категории, которые не удалось проверить. При пакетной обработке JPEG сохраняется как JPEG, остальные форматы — как PNG. PNG сохраняет прозрачность. Из анимированных и многостраничных файлов создаётся копия одного изображения без анимации и слоёв.

## Очистка без перекодирования

В окне Tauri включите **«Без перекодирования»** перед сохранением файла или пакета. Тот же режим доступен в CLI.

```sh
metasafe clean photo.webp --output photo_clean.webp --no-reencode
metasafe batch photo.jpg diagram.png image.webp --output-dir cleaned --no-reencode
```

Режим удаляет метаданные контейнера из статических JPEG, PNG и WebP и копирует сжатые данные изображения. Формат файла и прозрачность PNG и WebP сохраняются. Для анимации и файлов, которым нужен поворот или преобразование цвета, программа сообщает об ошибке и продолжает обрабатывать остальные файлы пакета. Удаление цветового профиля может изменить отображение цветов.

## Видео

Приложение Tauri и CLI открывают MP4, MOV, MKV и WebM. Установите `ffmpeg` и `ffprobe` и добавьте их в `PATH`. В окне программы можно просмотреть метаданные и воспроизвести совместимые дорожки, затем сохранить очищенные копии одного или нескольких файлов. Воспроизведение зависит от кодеков, доступных системному веб-движку.

```sh
metasafe inspect clip.mkv
metasafe clean clip.mkv --output clip_clean.mkv
mkdir -p cleaned
metasafe batch clip.mkv recording.webm --output-dir cleaned
metasafe verify cleaned/recording_clean.webm
```

При обычной очистке закодированные видео, звук и субтитры копируются в тот же формат контейнера. Программа удаляет поддерживаемые теги контейнера и главы, сохраняя текст субтитров и сигналы HDR. Перед публикацией просмотрите содержимое субтитров. Matroska-файлы с вложениями, например шрифтами, отклоняются, чтобы очистка не меняла отображение субтитров без предупреждения.

Опция `--strip-h264-sei` удаляет сообщения SEI из пакетов H.264 без перекодирования. Используйте её только для совместимого SDR-видео H.264. При обнаружении HDR или встроенных титров фильтрация отклоняется. Фильтр удаляет все обнаруженные сообщения SEI, включая другие данные, которые они могут содержать. Размер видео должен быть меньше 2 ГиБ, число дорожек — не более 32. Для больших файлов требуется свободное место для временного снимка исходника и очищенной копии. Отчёт не подтверждает удаление персональных данных внутри кодированных потоков и текста субтитров. Универсальной очистки потока для других кодеков, Dolby Vision, HDR10+ и произвольных данных нет.

## Linux

Чтобы установить локальную сборку для ARM64, выполните `sudo apt install ./MetaSafe_0.6.0_arm64.deb` в папке с пакетом. APT установит FFmpeg и зависимости для рабочего стола. Рекомендованные пакеты GStreamer расширяют поддержку воспроизведения. В Linux встроенный плеер получает выбранное видео через локальный адрес на том же устройстве (`127.0.0.1`).

Проверки GitHub Actions собирают CLI и пакет Tauri для Debian на Ubuntu 24.04. Для локальной сборки установите [зависимости Tauri для Linux](https://v2.tauri.app/start/prerequisites/#linux) и выполните команды из раздела ниже. Чтобы собрать пакет Debian, запустите `npm run tauri build -- --bundles deb` в папке `desktop/`. Для CLI выполните `cargo build --release --locked --no-default-features` в корне проекта.

## Запуск интерфейса Tauri

Установите Node.js, Rust 1.90 или новее и [системные зависимости Tauri](https://v2.tauri.app/start/prerequisites/). В корне проекта выполните:

```sh
cd desktop
npm ci
npm run tauri dev
```

Для сборки приложения под текущую ОС выполните `npm run tauri build` из папки `desktop/`.

## Сборка из исходников

Нужен Rust 1.88 или новее. В корне проекта выполните:

```sh
cargo build --release --locked --bins
```

Исполняемые файлы появятся в `target/release`. Можно также установить оба приложения через `cargo install --path . --locked`. Для сборки только CLI используйте `cargo build --release --locked --no-default-features --bin metasafe`.

## Границы проверки

Поддерживаются JPEG. Проверка охватывает EXIF, GPS в EXIF, XMP, IPTC, комментарии JPEG и ICC. Отчёт показывает неизвестные сегменты и данные после конца JPEG. Допускается служебный заголовок JFIF без миниатюры. `verify` также проверяет, декодируется ли JPEG.

Очистка перекодирует JPEG с качеством 90 и удаляет исходный профиль ICC. Размер, качество и цветопередача могут измениться. Лица, адреса и другие детали в пикселях сохраняются. Отчёт не подтверждает анонимность.

Разбор EXIF ограничен 1 024 полями, 32 каталогами TIFF и оценкой памяти в 1 МиБ. При превышении предела программа отмечает EXIF и GPS как непроверенные и отклоняет очистку.

Выбирайте папку вывода, которую могут изменять только доверенные пользователи. Это касается и родительских папок. MetaSafe сравнивает опубликованный файл с проверенной копией и сообщает о расхождении. Процесс с правом записи может подменить файл во время проверки или после неё.

Предел для исходных и выходных фотографий составляет 64 МиБ. Для декодирования действуют пределы 16 384 пикселя на сторону и 40 мегапикселей. Лимит выделений декодера применяется по возможности и не ограничивает всю память процесса. При аварийном завершении временный файл может остаться в папке назначения.
